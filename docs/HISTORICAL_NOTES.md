# 江戸表現チェック

本作は史実再現シミュレーターではなく、明るいライトアニメ調の江戸生活ゲーム。
厳密さより遊びやすさを優先するが、生活ディテールで江戸らしさを支える。

## 優先して見せる

- 長屋、路地、木戸、共同井戸
- 防火桶、纏、鳶口、町火消し
- 棒手振り、魚屋、瓦版屋、屑屋、古着
- 手拭い、前掛け、草履、脚絆
- 米ぬか、灰汁など日常の洗浄手段
- 汲み取りと農村肥料の循環
- 物干し、木桶、天秤棒、屋台

## 控える

- 常に富士山や城が見える構図
- 観光地のような提灯・看板過密
- 全員が新品の着物
- 刀・侍・忍者だけで江戸らしさを表現すること

## 火事表現

江戸の火事は大きな生活リスクだが、本作では恐怖演出より
「町内で役割を分担して動く」共同体の面白さに重点を置く。

ゲーム上の小火イベントは、実際の町火消し活動を圧縮・簡略化した表現であり、
消火そのものより避難、通路確保、桶、状況把握、連携を中心にする。

## 方針

史実とゲーム性が衝突した場合の優先順位:

1. プレイヤーに伝わる
2. ゲームとして楽しい
3. 江戸らしさを壊さない
4. 厳密な史実再現
