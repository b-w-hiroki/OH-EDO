# Responsive / Art Guide

## Visual direction
ライトなアニメ調、明るい昼光、親しみやすい表情。
重厚な時代劇や観光地的な「江戸記号盛り」には寄せない。

## Historical texture
長屋、井戸、路地、木戸、物干し、木桶、天秤棒、棒手振り、手拭い、前掛け、草履、脚絆、繕い跡を優先。
富士山・城・提灯は常用しない。

## Landscape >= 900px
- worldを広く見せる
- statusは横一列
- dialog overlayは下寄せ
- 情報パネルは横方向へ逃がす

## Compact 600–899px
- statusは折返し
- overlayの余白を縮小
-操作ヒントを簡潔に

## Portrait < 600px
- statusは3列程度のコンパクトグリッド
- Phaser viewは横画面の単なるcropにせず、幅100%で縮小
- dialog/job/resultは画面下寄せ
- 操作ヒントはタッチ操作前提の文言へ変更
- 主要ボタンは44px以上を目安
