# OH！EDO！ 参照モック準拠 UI仕様

## 1. 目的

ユーザー提供の横画面・縦画面モックを、単なる雰囲気参考ではなく**実装仕様**として扱う。

優先するのは以下。

1. 町の情景を主役にする
2. 人との会話を最も大きな行動として見せる
3. 必要情報は「紙の札 / 和紙カード」にまとめる
4. 横画面は「情景 + 右情報欄」
5. 縦画面は「会話 + 人 + 噂 + 大きい話すボタン」
6. デジタル方向パッドは表示しない
7. すべてのボタンは実際のゲーム状態・イベントに接続する

## 2. 横画面レイアウト

### 上段

左から以下の3ブロック。

- OH！EDO！ロゴ
- 日付 / 時間 / 現在地
- プレイヤーステータス

日付ブロックは以下の形式。

- 年数
- 季節
- 日数
- 時間帯
- 現在地

ステータスは以下を優先。

- 銭
- 信用
- 粋
- 人脈
- 腕前
- 衛生

町全体の安全・流行・景気は右サイドへ分離する。

### 中段

左 70〜75%：ゲームシーン
右 25〜30%：情報サイドバー

ゲームシーンは最も大きく見せる。
会話中は下側約30%へ会話パネルを重ねる。

### 右サイドバー

上から以下。

1. このあたりの人たち
2. 昨日の行動 → 今日の変化
3. この場所の小話
4. 今日のうわさ
5. 町の空気

人物カードは以下を表示。

- 顔アイコン
- 名前
- 関係状態
- 話すボタン

### 下段

エリアナビゲーション。

- 長屋前
- 井戸端
- 商店通り
- 火消し小屋
- 部屋
- 江戸の地図 / 覚え書き

各タブはアイコン + 名前 + 短い説明。

配色：

- 選択中：朱色 / 橙
- 通常：淡い藍 / 水色
- 補助：生成り / 和紙色

右端またはナビ直上に大きな「話す」CTAを置く。

## 3. 縦画面レイアウト

上から以下。

1. ロゴ + 日付 / 時間 / 現在地 + メニュー
2. プレイヤー情報 / ステータス
3. ゲームシーン
4. 会話パネル
5. このあたりの人たち
6. 今日のうわさ
7. 大きな「話す」CTA
8. 下部エリアナビ

縦画面では右サイドバーを廃止し、カードをシーン下へ積む。

「このあたりの人たち」と「今日のうわさ」は、幅に余裕がある場合は2列、
狭い端末では1列。

## 4. 会話パネル

会話はゲーム中の最重要UI。

- 生成り背景
- 茶色の名前札
- 話者ポートレート
- 本文
- 次へインジケータ
- 下部に十分な余白

会話開始時は軽く下から浮く。
背景の人物・情景を完全に隠さない。

## 5. 町の情景

「歴史再現」より「暮らしてみたい江戸」。

優先して見せるもの：

- 長屋
- のれん
- 物干し
- 桶
- 木箱
- 植木
- 井戸
- 魚屋
- 火消し道具
- 子ども
- 猫
- 春の花 / 桜
- 遠景の屋根

避ける：

- 黒く重い画面
- 無機質なRPGウィンドウ
- デジタル方向パッド
- 富士山・城・刀だけで江戸感を出すこと

## 6. 操作仕様

PC：

- WASD / 矢印：移動
- Space / E：会話
- NPCクリック：会話
- エリアタブ：移動

タッチ：

- NPCタップ：会話
- 「話す」ボタン：そのエリアの主要NPCと会話
- エリアタブ：移動
- デジタル方向パッドは表示しない

## 7. レスポンシブ基準

- 900px超：横画面レイアウト
- 600〜900px：1カラム + サイド情報2列
- 600px未満：縦画面レイアウト

## 8. Done条件

- 横画面が「町の情景 + 右情報欄 + 下部ナビ」に見える
- 縦画面が「情景 + 会話 + 人 + 噂 + 大きい話すボタン」に見える
- デジタルパッドが存在しない
- ステータスの情報密度がモックと同程度
- 人物カードから直接話せる
- 大きい「話す」CTAが実際にNPC会話を開始する
- 部屋 / 地図相当の操作が機能する
- 既存のDay1〜Day5進行を壊さない
- test / typecheck / build / smoke が通る
