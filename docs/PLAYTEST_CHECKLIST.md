# プレイテスト・チェックリスト

## 目的

OH！EDO！を「見た目の良い試作」ではなく、初見でも迷わず遊べる状態にするための確認項目。

## PC

- [ ] タイトル → 導入 → Day1 が自然につながる
- [ ] WASD / 矢印で移動できる
- [ ] Space / E で会話できる
- [ ] NPCを直接クリックして会話できる
- [ ] エリアタブで移動できる
- [ ] 会話中に誤移動しない
- [ ] Day1 → Day2 → 小火 → Day3 → 見回り → Day4 → 春祭り → Day5 が進行する

## スマホ / タッチ

- [ ] 方向パッドなしでプレイ可能
- [ ] エリアタブで場所を移動できる
- [ ] NPC本人をタップして会話できる
- [ ] 右/下の「話す」ボタンからも会話できる
- [ ] 会話送りがタップで行える
- [ ] 縦画面でカードがはみ出さない
- [ ] 下部エリアナビが操作を邪魔しない
- [ ] 文字サイズが小さすぎない

## ゲーム進行

- [ ] 今日の目当てを見れば次にやることが分かる
- [ ] 「昨日の行動 → 今日の変化」が理解できる
- [ ] 噂が時間で消える
- [ ] 評判タグは残る
- [ ] 評判タグがNPC会話に反映される
- [ ] 春祭りで対応する評判ボーナスが出る
- [ ] 古いセーブデータから読み込める
- [ ] 同じイベントを二重に開始できない

## 見た目

- [ ] 横画面は中央の町 + 右情報欄として成立
- [ ] 縦画面は会話中心で成立
- [ ] デジタルパッドが表示されない
- [ ] NPCと背景の判別がつく
- [ ] エリアごとの違いが見た目で伝わる
- [ ] 会話UIが背景に埋もれない

## 音

- [ ] 初回ユーザー操作後にSEが鳴る
- [ ] ブラウザの自動再生制限でエラーにならない
- [ ] 音がなくても進行に支障がない

## 不具合発見時

最低限、以下を記録する。

- 使用端末 / ブラウザ
- 画面サイズ
- Day
- エリア
- 直前に行った操作
- 期待した結果
- 実際の結果
