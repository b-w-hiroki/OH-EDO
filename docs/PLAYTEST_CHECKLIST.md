# プレイテスト・チェックリスト

## 目的

OH！EDO！を「見た目の良い試作」ではなく、初見でも迷わず遊べる状態にするための確認項目。

## PC

- [ ] タイトル → 導入 → Day1 が自然につながる
- [ ] WASD / 矢印で移動できる
- [ ] Space / E で会話できる
- [ ] NPCを直接クリックして会話できる
- [ ] エリアタブで移動できる
- [ ] 会話中に誤移動しない
- [ ] Day1 → Day5が進行する
- [ ] Day5 → Day6の次章移行が自然に分かる
- [ ] Day6 → Day10の町イベントが進行する

## スマホ / タッチ

- [ ] 方向パッドなしでプレイ可能
- [ ] エリアタブで場所を移動できる
- [ ] NPC本人をタップして会話できる
- [ ] 右/下の「話す」ボタンからも会話できる
- [ ] 会話送りがタップで行える
- [ ] 縦画面でカードがはみ出さない
- [ ] 下部エリアナビが操作を邪魔しない
- [ ] 文字サイズが小さすぎない

## ゲーム進行

- [ ] 今日の目当てを見れば次にやることが分かる
- [ ] 「昨日の行動 → 今日の変化」が理解できる
- [ ] 噂が時間で消える
- [ ] 評判タグは残る
- [ ] 評判タグがNPC会話に反映される
- [ ] 春祭りで対応する評判ボーナスが出る
- [ ] Day6〜Day10の選択が翌日や町の反応へつながって見える
- [ ] Day10で次の章へ続く余韻がある
- [ ] 古いセーブデータから読み込める
- [ ] 同じイベントを二重に開始できない

## 見た目

- [ ] 横画面は中央の町 + 右情報欄として成立
- [ ] 縦画面は会話中心で成立
- [ ] デジタルパッドが表示されない
- [ ] NPCと背景の判別がつく
- [ ] エリアごとの違いが見た目で伝わる
- [ ] 会話UIが背景に埋もれない

## 音

- [ ] 初回ユーザー操作後にSEが鳴る
- [ ] ブラウザの自動再生制限でエラーにならない
- [ ] 音がなくても進行に支障がない

## 不具合発見時

最低限、以下を記録する。

- 使用端末 / ブラウザ
- 画面サイズ
- Day
- エリア
- 直前に行った操作
- 期待した結果
- 実際の結果


## 初見ユーザー評価

- [ ] 3人以上がDay5まで到達
- [ ] 2人以上がDay6以降へ進む
- [ ] 2/3以上が「昨日の行動が今日に返る」を自分の言葉で説明できる
- [ ] 同じ箇所で2人以上が迷った場合は修正Issueを作る
- [ ] Day1→Day5 / Day1→Day10の所要時間を記録する
- [ ] Day6〜Day10がミニゲーム集ではなく町生活の続きに感じるか確認する


## Playtest mode

URLの末尾に `?playtest=1` を付けて起動すると、覚え書き画面に **プレイ記録をコピー** が表示される。

記録内容:
- Day到達時刻
- 主要な選択
- Day6〜Day10のtown-event選択
- 現在Day / ランク
- playerActions
- completedTownEventIds

外部サーバーへは送信せず、sessionStorage内だけで保持する。テスト終了時にコピーしたJSONを回収する。
