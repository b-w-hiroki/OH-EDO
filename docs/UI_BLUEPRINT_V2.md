# OH！EDO！ UI BLUEPRINT V2

参照モックを「雰囲気」ではなく、実装寸法として固定するための設計図。

## 1. 横画面・通常時（基準 1600×1000）

- 上部ヘッダー: 72px
  - ロゴ: 170×58
  - 日付 / 時間 / 現在地: 中央可変
  - メニュー: 右端
- ステータス帯: 82px
- 今日の目当て: 38px
- メイン領域:
  - 左メイン情景: 74%
  - 右情報欄: 26%
- メイン情景:
  - 16:9
  - 主人公: 左 8%、幅 36%、高さ 91%
  - 主要NPC: 右 6%、幅 35%、高さ 88%
  - 2人目NPC: 右 37%、幅 15%、高さ 42%
- 下部:
  - エリアナビ + 話すCTA: 86〜96px
  - 町の声: 36px

### 目的
「歩行マップ」ではなく「江戸の生活情景」を一目で見せる。

---

## 2. 横画面・会話時（基準 1600×1000）

通常画面を維持しつつ、会話だけ下側へ重ねる。

- 背景: そのまま表示
- 主人公 / NPC: 大きいまま維持
- 会話枠:
  - 横幅 58〜64%
  - 高さ 160〜210px
  - 下から 24〜36px
  - 名前札は左上へ少しはみ出す
- 会話相手の立ち絵:
  - 会話枠の横に追加で重ねず、情景側の大キャラをそのまま利用
- 右情報欄:
  - 表示維持
  - ただし会話対象カードのみ軽くハイライト

### 目的
会話UIを「別画面」にせず、町の情景の中で会話しているように見せる。

---

## 3. 縦画面・通常時（基準 430×932）

- 上部:
  - ロゴ + 日付 / 時間 / 現在地
  - 約 120px
- ステータス:
  - 2〜3列
  - 約 120px
- 情景:
  - 4:5.25
  - 高さ 500〜560px相当
  - 主人公: 左 -11%、幅 64%、高さ 74%
  - 主要NPC: 右 -12%、幅 65%、高さ 73%
- 情報カード:
  - 「このあたりの人たち」
  - 「今日のうわさ」
- 大きい話すCTA:
  - 高さ 72〜84px
- 下部ナビ:
  - 横スクロール
  - 1タブ 112〜120px

### 目的
縦では「会話と人物」を優先し、右サイドバーという概念を捨てる。

---

## 4. 縦画面・会話時（基準 430×932）

- 情景を上側に残す
- キャラは通常時の大きさを維持
- 会話枠:
  - 幅 100%
  - 下端へ配置
  - 130〜170px
- 会話ポートレート:
  - 54px前後
- 人物カード / 噂カード:
  - 会話中は画面下へ押し出してよい
- 話すCTA:
  - 会話中は非表示
- 下部ナビ:
  - 会話中は操作不可でも表示維持可能

### 目的
「スマホ用RPGウィンドウ」ではなく、モックの縦画面のように
大きい人物と背景を主役にする。

---

## 実装原則

1. 町の通常表示は固定情景型を正とする
2. Phaser歩行画面は主表示から外す
3. エリア移動は下部タブで成立させる
4. NPC会話はキャラ本体クリック / タップでも成立させる
5. デジタル方向パッドは表示しない
6. 文字は画像へ焼かず、React側でライブ表示
7. 背景・立ち絵・UIは独立レイヤーとして組む
8. 横 / 縦は同じDOMを無理に縮小せず、CSSで構図を変える

## Done条件

- 初見でモックと同じ情報優先順位に見える
- 背景が「マップ」ではなく「情景」に見える
- 主人公と主要NPCが画面の主役になる
- 会話時に人物が小さくならない
- 横と縦で別々に成立する
- Day1〜Day5進行を壊さない
- test / typecheck / build / smoke が成功する
