# OH-EDO アウトゲーム導線整理

## 目的

町で人に会い、会話し、選び、結果を受け取る一日の体験を止めずに、再開時と翌日の目的だけを迷わず確認できる状態をつくる。

この文書は、現行実装と今後の提案を分けるための設計メモである。ショップ、所持品、訓練、新通貨、物語の新章は実装対象に含めない。

## 現行実装

### 町へ出る前

- タイトル画面には、保存があれば「つづきから」、なければ「大江戸町へ」の主ボタンが一つある。
- 独立したホーム画面、章選択、装備・編成画面はない。
- 町では日付、時刻、現在地、次の目的を確認して、移動先または会話相手を選ぶ。
- 「部屋」は町の一地点として扱われており、育成や所持品管理の拠点ではない。

### 一日の体験

基本ループは次の通り。

1. 町で現在の目的と近くの人物を確認する。
2. 移動または会話で出来事を進める。
3. 選択肢で行動を決める。
4. 結果画面で変化と報酬を確認する。
5. 夜または次の日へ進み、町へ戻る。

### 保存されるもの

現行の保存データには、日付・時刻・現在地、能力・所持金・身分、町の状態、人物関係、噂と履歴、評判、行動・判断ログ、進行中／完了済みの町イベント、現在の画面と会話位置、直前の結果が含まれる。

状態更新ごとに自動保存され、会話中、選択直前、結果確認中を含む主要画面が復元対象になっている。古い形式の保存データを読み替える仕組みと、不正な保存データを開始状態へ戻す保護もある。

### 記録の確認

「記録帳」に、主人公と町の数値、人物関係、評判、噂、最近の出来事が集約されている。現状では、これがアウトゲーム情報を確認する唯一のまとまった画面である。

### 現在ないもの

- 所持品・装備・倉庫
- ショップ
- 訓練・スキルツリー
- 章選択・周回選択
- 独立したクエスト一覧、報酬一覧、人物一覧

存在しない仕組みを前提にメニューだけを増やすと、町へ入るまでの手数と理解負荷が増えるため、現時点では追加しない。

## 体験の方向（設計提案・未実装）

目指すのは、江戸で誰に会い、どこへ行き、何を引き受けるかを自分で選び、その結果として人物関係、仕事の幅、町での立場が少しずつ広がる体験である。参考作品の固有UI、アート、個別システムを再現するのではなく、「拠点から次の一手を選び、生き方を積み重ねる」という体験の方向だけを取り入れる。

江戸の背景と人物を主役にし、管理表を眺める時間より、町へ出て人と会う時間を長くする。独立したショップ、訓練、所持品、複雑な経済は、用途と遊びが承認されるまで追加しない。

### 最初に試す小さな一巡

1. **町で次の一手を選ぶ**：現在地から、会う人物、訪問先、進行可能な仕事のいずれかを選ぶ。
2. **一つの活動を行う**：短い会話、依頼、仕事、町の出来事のうち一つを進める。
3. **結果を受け取る**：場面の結末と、変化した関係・評判・能力・手掛かりだけを確認する。
4. **町へ戻る**：人物の反応や次の手掛かりが更新され、別の一手を選べる。

この一巡が面白く、保存と再開が安定することを確認してから、活動や成長の種類を増やす。一度に複数の新システムを導入しない。

### 現行Day進行とのつなぎ方

- 現在のDay1〜Day10は、人物、場所、仕事、結果の読み方を覚える「導入の連続日」として維持できる。
- 導入中も町へ戻るたびに次の一手を選ばせ、一本道の会話だけで翌日へ送らない。
- 活動の確定時に既存の時刻を進め、一日の終わりは既存の日替わり処理へ接続する。
- 完了済みイベント、人物関係、噂、評判、現在画面の保存方式を正とし、新しい進行は同じ確定単位へ追加する。
- 再読み込み時は、町、活動中、選択前、結果確認中のいずれも同じ地点から再開し、時間や報酬を重複させない。

### 選択に意味を持たせる基準

- 選択前に、すぐ起きる変化を短く示す。数値をすべて見せるのではなく、判断に必要な影響だけを示す。
- 選択後は、場面の反応を先に見せ、その後に変化した項目だけを結果として示す。
- 選択は、報酬量だけでなく「誰との関係を優先するか」「町でどんな評判を得るか」「次にどの仕事へつながるか」の少なくとも一つを変える。
- 結果が同じ選択肢を数だけ増やさない。違いを説明できない案は統合する。
- 取り返しのつかない選択や大きな時間消費は、確定前に明示する。

### 見える目標

- **今の一手**：次に会える人物、行ける場所、進められる仕事から一つを選べる。
- **近い目標**：人物との約束、進行中の依頼、次の日までに確かめる手掛かりを一つ示す。
- **長い目標**：町での立場や生き方の方向を記録帳で確認できる。

町画面で常時強調するのは「今の一手」と近い目標までとし、長い履歴や全数値は記録帳へ置く。

### 必要最小限の画面

1. タイトル兼ホーム：再開内容を確認する。
2. 町／訪問先：背景と人物を見ながら次の一手を選ぶ。
3. 活動：会話、依頼、仕事の選択を行う。
4. 結果：場面の結末と変化だけを確認する。
5. 記録帳：関係、進行中の約束、町での立場を後から確認する。

依頼一覧、人物一覧、育成、所持品をそれぞれ独立画面に分けない。必要性が生まれた情報から、記録帳内の一節として試す。

### ゲームらしい見せ方

- 江戸の背景と人物を最も広い面積で見せ、説明紙面は選択や結果の時だけ重ねる。
- 選択肢は短い札として示し、札全体を押せるようにする。押下、選択、結果の反応を音、動き、色の強弱で返す。
- 結果は物語上の一文を先に、変化した関係や能力を後に示す。管理表を常時見せない。
- 新しい装飾を増やす前に、既存の承認背景、人物絵、紙、判、色を再利用する。
- 文字を縮めて情報を詰めず、補足は必要な時だけ開く。主操作と物語上の反応は折りたたまない。

## 提案する最小構成（未実装）

### 1. タイトル兼ホーム

保存がある場合は「つづきから」を主操作にし、その近くに日付、時刻、現在地、次の目的、最終保存時刻を一行で示す。「はじめから」は副操作とし、確認を経ない限り保存を消さない。

新しい独立ホーム画面は増やさず、タイトルそのものを再開判断の場所にする。

### 2. 町へ出る前

専用の準備画面は設けない。日替わり時の短いまとめで「昨日変わったこと」「今日の目的」「最初の手掛かり」を示し、そのまま町へ戻す。移動先は既存の町画面で選ぶ。

### 3. 一日の終わり

既存の結果表示と日替わり演出を使い、次の三点だけを簡潔に引き継ぐ。

- 今回変わったもの
- まだ残っている手掛かり
- 次の日または次の章で目指すこと

詳細な履歴は記録帳へ残し、結果画面に全情報を重複表示しない。

### 4. 記録帳

アウトゲーム情報は記録帳に集約する。必要なら同一画面内を「自分」「人物」「町と噂」「これまで」の順に整理するが、別々のメニューや専用画面へ分割しない。

### 5. 次の日・次章の目標

現在の「次の目的」「次の手掛かり」を正とする。章の再選択や分岐やり直しが実際に必要になるまでは、章選択画面を作らない。

## 必要な画面と不要なメニュー

### 最小限必要

1. タイトル兼ホーム：再開内容の確認、続行、確認付きの新規開始
2. 町：目的確認、人物との会話、移動
3. 記録帳：持ち越した状態と履歴の確認
4. 結果／日替わり：今回の変化と次の目的の受け渡し

「部屋」は引き続き町の中の場面とし、別の管理メニューにはしない。

### 現時点では不要

- ショップ、所持品、装備、倉庫
- 訓練、スキルツリー
- 日課、汎用クエスト一覧
- 章選択、周回選択
- 人物関係、噂、報酬をそれぞれ分けた専用画面
- 新しい通貨やポイント

## 情報密度と段階表示の基準

- 各画面の最初の視界では「現在地・次の目的・主操作」を優先し、履歴や補足説明を同じ強さで並べない。
- 結果画面は変化した項目だけを先に示し、変化のない数値は記録帳で確認できるようにする。
- 選択肢は「名前 → 意味 → 影響 → 決定」の順にまとまりを作り、影響値は折り返せる単位で表示する。
- 噂や履歴などの補足情報は、存在する時だけ表示する。空の状態を説明するためだけのパネルは増やさない。
- 文字を小さくして収めない。本文は実機で読める大きさを保ち、段落間、パネル内、操作前に意味のある余白を置く。
- 余白のために主操作を画面外へ追い出さない。375×667でも選択内容と決定操作の関係が同時に理解できることを確認する。
- 詳細を折りたたむ場合も、現在の目的と確定前の影響は隠さない。詳細表示は再確認用の情報に限る。

## 優先順位

1. **P0 — 再開の明瞭さと安全性**：何を再開するか見えること、新規開始で誤って保存を失わないこと。
2. **P1 — 記録帳の情報設計**：持ち越し情報を一か所で短時間に確認できること。
3. **P2 — 一日の引き継ぎ**：結果から翌日の目的までが途切れず、同じ説明が重複しないこと。
4. **P3 — 将来機能**：物語側に章の再選択や所持品の用途が生まれた時だけ、対応するメニューを検討すること。

## 保存・戻る・再開の Done 条件

### 保存

- 確定した会話送り、選択、報酬、日替わりごとに、対応する状態が一度だけ保存される。
- 選択肢の連打や再読み込みで、報酬、行動ログ、完了済みイベントが重複しない。
- 保存中に通信や演出が失敗しても、直前の確定状態から遊びを続けられる。
- 保存形式の更新後も、対応対象の旧データを移行でき、不正なデータは安全に開始状態へ戻る。

### 戻る

- 記録帳や部屋から閉じた時、開く前の町と現在地へ戻る。
- 会話、選択、結果でブラウザの戻る操作を必須にしない。
- 「はじめから」は確認を表示し、キャンセル時は保存内容と現在画面を変更しない。

### 再開

- タイトルで、日付、時刻、現在地、次の目的、最終保存時刻を確認してから続行できる。
- 会話中は同じ話者・同じ文、選択前は未選択の状態、結果画面では受け取り済みの結果から再開する。
- 再開直後に同じ報酬や日替わり処理が再実行されない。
- 375×667、390×844、844×390、デスクトップで、続行、新規開始の確認、記録帳から戻る、会話中・選択前・結果画面の再読み込みを検証する。

## 完成の判断

プレイヤーがタイトルを見て十秒以内に「どこから再開し、次に何をするか」を説明でき、町へ入る前に不要な管理作業を求められず、一日の結果が翌日の目的へ自然につながることを、アウトゲーム導線の完成条件とする。
