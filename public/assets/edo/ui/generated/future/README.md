# OH-EDO future action icons

These 512 × 512 transparent PNGs are production-ready visual assets, but are
intentionally not wired into the runtime yet. They follow the approved town
navigation palette and object rendering:

- `quest-scroll.png`: quest/request summaries and objective notices.
- `reward-koban.png`: reward and result summaries.
- `resume-plaque.png`: save/resume entry points.

All three use the same scale, lighting, safe area and indigo/vermilion/cream
palette. Keep at least 44 CSS px for interactive uses; do not add new mechanics
solely to use these assets.
